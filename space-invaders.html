Space Invaders Clone (C)

  1. Portfolio
  2. Space Invaders

Project Information

  • Role: Solo Developer
  • Language: C
  • Genre: Arcade Shooter
  • Tools: Visual Studio, ESAT Framework

Mastering the Fundamentals in C

Built entirely from scratch, this implementation of the classic 1978 arcade game marked my first deep dive into video game programming. Developing outside of commercial game engines like Unity or UE5 required writing the core game loop, handling memory directly, and engineering custom logic for every on-screen entity. Additionally, I personally edited and integrated all visual assets to achieve a highly polished retro aesthetic.

Technical Implementation

  • Entity Data Structures: Engineered custom C structs to independently manage the state, coordinates, active flags, and parameters of the player ship, enemy swarm, projectiles, and destructible barriers.
  • State Machine & Game Loop: Programmed a robust core loop capable of handling frame-independent calculations and managing smooth state transitions across the Main Menu, active Gameplay, and Game Over screens.
  • Custom Collision System: Developed mathematically precise AABB collision checks to process interactions between projectiles and entities, including a tiered damage system for environmental barriers.

The Challenge & Learning

The most significant architectural hurdle was decoupling the enemy swarm's behavior. Initially, the aliens moved as a single monolithic block, which limited gameplay possibilities. I refactored the logic to iterate through an array of 55 enemy structs, calculating individual movement offsets and animation states per frame. To replicate authentic arcade difficulty, I also engineered a column-checking algorithm that ensures only the bottom-most active enemy in any given vertical line is permitted to fire projectiles at the player.
